# Applied AI Systems Portfolio — AI Operations

## Purpose

This directory controls startup, current state, and closeout for the public portfolio repository.

It exists to prevent:

- the public site from drifting away from the private evidence audit;
- live prototypes being mistaken for approved direction;
- case studies multiplying before the homepage hierarchy is settled;
- public writing becoming repetitive, overly technical, or internally focused;
- future sessions continuing from conversation memory instead of current files;
- resume and portfolio claims diverging.

## Repository Role

`RichBayer/applied-ai-systems-portfolio` owns the public presentation layer:

- GitHub-native README;
- GitHub Pages website;
- public case studies;
- public-safe diagrams and screenshots;
- future resume asset;
- navigation, accessibility, and public metadata.

It does not own claim authority.

Private claim and planning authority remains:

`RichBayer/career-positioning-audit`

## Core Files

- `portfolio_resume_prompt.md` — current public state and fresh-session startup
- `documentation_closeout_protocol.md` — mandatory end-of-session reconciliation
